# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security issue or flaw that could cause deadlock, lock bypass, or denial of service in distributed background task execution:

1. **Do not create a public issue.**
2. Email the maintainer at `egecagintepe@gmail.com` or submit a private GitHub Security Advisory.
3. Provide details on how to reproduce the issue.

We will acknowledge receipt within 48 hours.
